# SmartQA 知识库数据模板

本目录包含 SmartQA 知识库录入所需的 CSV 模板文件。

## 文件说明

| 文件 | 说明 |
|------|------|
| `产品知识表.csv` | 产品基础信息、价格、参数、常见问题 |
| `售后政策表.csv` | 退换货、破损理赔、质保等售后规则 |
| `generate_templates.py` | 模板生成脚本（可重新运行以恢复初始模板） |

## 填写指南

### 产品知识表

1. 用 Excel 或 WPS 打开 `产品知识表.csv`（UTF-8 编码）
2. **必填字段**：品类、产品名称、规格型号、单位、状态
3. **价格字段**：面价和批发价请填写实际数字（如 `35.5元/m²`），不要留占位符
4. **批发条件**：格式建议为 `≥1000m²` 或 `≥100桶`，标明起批数量或金额
5. **核心参数**：填写产品的主要技术指标，多个参数用逗号或分号分隔
6. **状态**：从 `在售` / `缺货` / `下架` 中选择填写
7. 示例行仅供参考，请根据实际产品信息修改

### 售后政策表

1. 已预填常见售后政策模板，可根据公司实际规则修改
2. **政策类型**：从 `退换货` / `破损理赔` / `质量投诉` / `质保` / `退款` 中选择
3. **时效**：填写具体的天数或工作日
4. 如需新增政策，直接在对应类型下方添加新行即可

### 编码说明

- 文件使用 **UTF-8 with BOM** 编码，Excel 可直接打开无乱码
- 如用记事本打开出现乱码，请用 Excel/WPS 打开

### 重新生成模板

如果模板被改乱了，可以重新运行生成脚本恢复初始模板：

```bash
python generate_templates.py
```

> 注意：重新运行会覆盖当前文件，请先备份已填写的数据。

## 导入到 Dify 知识库

1. 在 Dify 后台创建两个知识库：`产品知识库` 和 `售后政策库`
2. 将对应的 CSV 文件上传导入
3. 在 Dify Workflow 中配置 Knowledge Retrieval Node 引用对应知识库
